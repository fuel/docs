Functions

Fuel provides a few global functions for things that are used in the framework, but may also be handy in your own applications. These functiona re defined in base.php, which can be found in the Fuel core directory.

call_fuel_func_array()

A faster equivalent to call_user_func_array(), especially in older PHP versions.

http_build_url()

The reverse function of parse_url(). It is defined in a PECL extension (pecl_http >= 0.21.0), but not every server has the extension loaded, and not everyone has the option to change installed PHP modules.

in_arrayi()

Equivalent to the built-in function in_array(), but does a case-insensitive check.

e(string $s)

A shortcut to \Security::htmlentities(), mainly used in view files.

__(string $string, array $params, string|null $default, string|null $language)

A shortcut to \Lang::get(), mainly used in view files.

logger(string|int $level, string $msg, string|array|null $context)

A shortcut to \Log::write().

render(string $view, array|null $data, bool $auto_filter)

A shortcut to creating a View object using \View::forge(), and then calling the render() method of the object.

get_common_path(array $paths)

Takes an array with one of more fully qualified file paths, and returns the common parent. Does not work for Windows paths!

Parameters
Param Default Description
$paths required An array contains one or more strings representing fully qualified filenames of file paths
Returns A string containing the common parent for all paths given. "/" (the file system root) will be returned of there was no common parent.
Example 
// Returns "/data".
$paths = array('/data/dir1', '/data/dir2');
echo get_common_path($paths);

get_real_class(string $class)

Uses Reflection to find and return the real class name. Useful when using class aliasing.

Parameters
Param Default Description
$class required Fully namespaced class name, without the leading backslash.
Returns A string containing the real class.
Example 
// Returns "Fuel\Core\Fuel", if not overloaded in the app
echo get_real_class('Fuel');

html_tag(string $tag, array $attr, string|null $content)

Generated a string containing a HTML tag, including attributes and optional content for tag types that have data between open and close tags.

Parameters
Param Default Description
$tag required HTML tag to generate.
$attr array() Array of tag attributes.
$content null Optional content for tags that may have any content.
Returns A string containing a HTML tag.
Example 
// Returns "<a href="https://fuelphp.com">Fuel Website</a>"
echo html_tag('a', array('href' => 'https://fuelphp.com'), 'Fuel Website');

import(string $class, string $folder)

Imports a Fuel core class, and loads the App overload if defined as well.

Parameters
Param Default Description
$class required Class name, or relative path and class name in case the load is from a subdirectory.
$folder 'classes' Directory the class has to be loaded from. In general, this is always "classes", the Fuel standard location.
$content null Optional content for tags that may have any content.
Example 
// will "require" COREPATH/classes/controller/rest.php
// and APPPATH/classes/controller/rest.php if it exists.
import('controller/rest', 'classes');

is_uuid(string $uuid)

Checks if the given string is in valid UUID format.

Parameters
Param Default Description
$uuid required String to test for a valid UUID.
Returns True if the string is a valid UUID, false if not.
Example 
// will return true
$valid = is_uuid('dedd6906-de08-4b7f-b4de-46ae04942516');

// will return false, 'x' is not a valid character
$valid = is_uuid('dedd6906-xe08-4b7f-b4de-46ae04942516');

array_to_attr(array $attr)

Takes an array of attributes and turns it into a string for an html tag.

Parameters
Param Default Description
$attr required Array of HTML tag attributes.
Returns A stringified version of the attributes.
Example 
// Returns 'href="https://fuelphp.com disabled="disabled";
echo array_to_attr(array('href' => 'https://fuelphp.com', 'disabled' => true, 'readonly' => false));

tempdir()

Creates a temporary directory with a fuel prefixed unique name. In case of a collision, the existing directory will be deleted.

Returns A string containing a fully qualified path.
Example 
// May return something like "/tmp/fuelv5kjoreotn66e4Xhq8f"
echo tempdir();

is_windows()

Checks if the application runs on a Windows platform.

Returns True if the server OS is Windows, false if not.
Example 
// will return false on Linux
$windows = is_windows();
