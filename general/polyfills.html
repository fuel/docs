Polyfills

Fuel provides polyfills for popular functions added to PHP after the release of PHP 5.3.

Function Description
array_first() Returns the first value from an array. Introduced in PHP 8.5.
array_last() Returns the last value from an array. Introduced in PHP 8.5.
array_key_first() Returns the first key from an array. Introduced in PHP 7.3.
array_key_last() Returns the last key from an array. Introduced in PHP 7.3.
hash_pbkdf2() Implements PBKDF2 hashing. Introduced in PHP 5.5.
json_validate() Checks if a string contains valid JSON. Introduced in PHP 8.3.
http_build_url() The reverse function of parse_url(). It is defined in a PECL extension, but not every server has the extension loaded, and not everyone has the option to change installed PHP modules. Defined in pecl_http >= 0.21.0.
