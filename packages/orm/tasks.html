Tasks

The ORM package comes with tasks that automate things, thus making your life just that little bit easier.

ModelDBCheck

The modeldbcheck task allows you to check your application model definition against the current database schema.

The task will scan your application "classes" directories, in the app, and all defined model and package paths, for model classes that extend "\Orm\Model", either directly, or via a base class.

For every ORM model found, it will connect to the database using the models' defined table name, and retrieve the database schema for that table. It will then verify if all columns defined in the schema are present in the model properties list. If not, it will generate a basic array for that column, which you can simply copy and paste into the model. It will also warn you if you have columns defined that are no longer present in the schema. 

$ php oil refine modeldbcheck

Which will return something like 

Enumerate application models...
10 ORM database models found to verify

If you define and run your own migrations, there is usually no mismatch detected. But if your database is designed and managed by a third party, or is part of another application, you might find the schema changed since the last time you checked or worked on the application.

In these cases it is important to check, and missing columns in your model properties definition aren't detected until you want to access a column, or you do an INSERT or UPDATE and a missing column is defined in the schame as "NOT NULL", in which case the query will fail.
